A one-line weather forecast for a city that does not exist, written for
make.fun's "Charm the Commuter: Forecast a City That Isn't" bounty.

## Run it

```sh
node main.ts
```

It writes a single charming forecast line (140 characters at most) to
`/output/entry.txt`. Node 22, standard library only, no network, fully
deterministic.
